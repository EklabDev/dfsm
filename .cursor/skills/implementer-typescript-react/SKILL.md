# Implementer: TypeScript + React

## When to use
UI feature or client-heavy change in TS+React.

## MUST
- Prefer strict typing; avoid unsafe casts without rationale.
- Hooks and effects: document dependencies; avoid stale closures.
- Performance: memoization only when measured.
- Apply security-redlines for XSS and auth handling.

## Verification
- [ ] Lint/typecheck commands run or listed
- [ ] Basic a11y for interactive elements considered
