🏗️ System Architecture & Orchestration Flow

DFSM coordinates state transitions deterministically across distributed processes. If an error occurs in any step, the engine automatically activates the LIFO Saga compensation unwind, reversing previous operations in exact inverse order: 

flowchart TD
    Created["1. State: created"] -->|"SUBMIT_ORDER [reserveInventory]"| Reserved["2. State: inventory_reserved\n(Pushes releaseInventory to Saga Stack)"]
    Reserved -->|"AUTHORIZE_PAYMENT [authorizePayment]"| Fulfilling["3. State: fulfilling (Parallel)\n(Pushes refundPayment to Saga Stack)"]
    
    subgraph Parallel Fulfillment
        Fulfilling --> Packaging["packaging: packing -> packed"]
        Fulfilling --> Shipping["shipping: booking_carrier -> carrier_booked"]
    end

    Packaging & Shipping -->|"Automatic onDone"| Delivered["4. State: delivered (COMPLETED)"]

    Reserved -.->|"Payment Fails / Max Retries"| Error["Error State (Rollback Initiated)"]
    Error -.->|"LIFO Step 1"| Rel["Unwind: releaseInventory"]
    Rel -.-> Compensated["Status: COMPENSATED"]
    Compensated -->|"RESET_ORDER"| Created

🔄 4-Layer Policy Precedence Pipeline

Policies merge across four hierarchical layers: Code Decorator/Annotation > Transition YAML > Machine Defaults > Global Registry. Retries feature non-multiplying backoff (Fixed, Linear, Exponential) with jitter.

🛡️ Resilient Circuit Breakers

Each handler maintains a sliding-window failure monitor transitioning between CLOSED, OPEN, and HALF-OPEN states to protect downstream systems.

🚀 Polyglot Quick Start (How-To)

import { DfsmActor, parseYamlMachine, FSMRegistry } from "@eklabdev/dfsm";

interface OrderContext {
  orderId: string;
  amount: number;
}

const yaml = `
dfsm: "1.0"
id: order-machine
version: "1.0.0"
initial: draft
states:
  draft:
    on:
      SUBMIT: processing
  processing:
    on:
      COMPLETE: fulfilled
  fulfilled:
    type: final
`;

const machine = parseYamlMachine(yaml);
const actor = new DfsmActor<OrderContext>(machine);

// Start instance
await actor.start("order-101", { orderId: "order-101", amount: 150.0 });

// Transition 1: draft -> processing
const res1 = await actor.transition("order-101", "SUBMIT");
console.log(`Current state: ${res1.currentState} | Status: ${res1.status}`);

// Transition 2: processing -> fulfilled (Final state!)
const res2 = await actor.transition("order-101", "COMPLETE");
console.log(`Final state: ${res2.currentState} | Status: ${res2.status}`);
import io.github.eklabdev.dfsm.actor.DfsmActor;
import io.github.eklabdev.dfsm.definition.MachineDefinition;
import io.github.eklabdev.dfsm.definition.YamlParser;
import io.github.eklabdev.dfsm.registry.FSMRegistry;

public class Main {
    public record OrderContext(String orderId, double amount) {}

    public static void main(String[] args) throws Exception {
        String yaml = """
            dfsm: "1.0"
            id: order-machine
            version: "1.0.0"
            initial: draft
            states:
              draft:
                on:
                  SUBMIT: processing
              processing:
                on:
                  COMPLETE: fulfilled
              fulfilled:
                type: final
            """;

        MachineDefinition machine = YamlParser.parse(yaml);
        DfsmActor<OrderContext> actor = new DfsmActor<>(machine, new FSMRegistry());

        actor.start("order-101", new OrderContext("order-101", 150.0)).get();
        var res = actor.transition("order-101", "SUBMIT").get();
        System.out.println("Current state: " + res.currentState() + " | Status: " + res.status());
    }
}

🎯 Canonical Conformance Suite (6 Scenarios)

Every language pack runner passes the exact same 6 canonical scenarios:

1. Atomic Cycle & Default Error

Cycles red -> green -> yellow and routes unhandled exceptions to implicit default error state.

2. Hierarchical Bubbling Cancel

Enters child state active.authorizing and cleanly bubbles parent event CANCEL to cancelled.

3. Hierarchical onDone Cascade

Child reaching final state captured triggers parent's onDone directly to settled.

4. Parallel Regions Joint onDone

Orthogonal regions advance concurrently; joint onDone triggers only when all regions reach final.

5. 4-Layer Precedence Pipeline

Code decorator/annotation (retry=4) overrides YAML (retry=3), inheriting circuit breaker; routes to fallback.

6. LIFO Saga Compensation Rollback

Unwinds recorded compensation steps in reverse order (Hotel then Flight) into COMPENSATED state.
